# Data sources and coverage

This repository mirrors the public methodology notes for [Stardew Valley Planner](https://www.stardewvalleywiki.net/), an unofficial fan-made planning site.

The site keeps a source registry for every dataset:

- Official Stardew Valley Wiki page and mirror
- Bilibili wiki page for Chinese terminology cross-checks
- record count
- check date
- coverage status: sampled or checked

Live registry: https://www.stardewvalleywiki.net/about/sources

## Notes

- "Sampled" means counts and key fields were compared with the sources.
- "Checked" means the complete record set or name coverage was compared; individual stats may still be sampled.
- Corrections update the data, the check date, and the affected page together.
